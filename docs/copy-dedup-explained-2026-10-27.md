# 文案工坊「查重」说明（决策 D5 参考）

> 用途：说明文案工坊的查重功能是什么、为什么有、怎么算，以及原清单里「查重阈值校准」指的是什么，供决定保留还是删除。
> 对应：文案工坊任务书 FR-R2 / §3.5 / AC-R2 / AC-R3（F3）；技术方案 2.2「查重：素人线改写文案 vs 对标原文，相似度 >30% 退回」。
> 代码：`server/src/modules/copy/text.ts`（算法）、`server/src/modules/copy/service.ts` 预检（触发与拦截）。

---

## 1. 一句话说明

查重 = 检查**「对标视频改写」出来的文案里，有多少内容是照搬对标原文的**。

对标视频的口播原文由系统自动转写出来（百炼语音转文案），运营据此改写成自己的稿子。查重就是在**提交审核前**，拿改写稿和这份原文比一比，看是不是「换汤不换药」。

## 2. 什么时候生效

| 条件 | 行为 |
|---|---|
| 文案来源是**对标视频**（`source=benchmark`），且有转写原文 | 提交前的「预检」会算一个相似度 |
| 人物属于**素人矩阵线**，相似度 **> 30%** | **阻止提交**，提示「请继续改写」 |
| 人物属于经理 IP 线 / 员工 KOS 线 | **只提示**相似度，不拦截 |
| 来源是资讯、文章、手动输入 | **不查重**（没有可比的「别人的原稿」） |

也就是说：它只在「素人号改写竞品爆款」这一个场景里会拦人，其他场景最多显示一个数字。

## 3. 为什么要有

素人矩阵号的典型做法是「拿对标爆款视频改写」。如果改写稿大段照搬原文：

- 平台容易判定为**搬运 / 非原创**，轻则限流，重则处罚账号；
- 有**抄袭竞品口播文案**的版权风险。

所以产品需求（技术方案 2.2）要求：素人线改写稿与对标原文相似度超过 30% 时退回重写。经理 IP、员工 KOS 线的内容一般是自己的观点表达，只做提示。

## 4. 怎么算（带例子）

1. **清洗**：去掉标点和空格、全角转半角、英文转小写；风险提示块不参与。
2. **切片**：把文字按「连续 5 个字」一组切开（技术上叫 5-gram）。
3. **算比例**：看**改写稿**的这些 5 字组里，有多少组在**原文**里也出现过。

```
相似度 = 改写稿中「原文里也有」的 5 字组数量 ÷ 改写稿的 5 字组总数
```

**例子**

- 原文：`基金定投适合上班族长期坚持`
- 改写稿 A：`基金定投适合上班族慢慢来`
  - 改写稿 A 的 5 字组：基金定投适、金定投适合、定投适合上、投适合上班、适合上班族、合上班族慢、上班族慢慢、班族慢慢来（共 8 组）
  - 其中前 5 组在原文里出现过 → 相似度 = 5 / 8 = **62.5%** → 素人线会被拦截
- 改写稿 B：`工薪族每月固定投一点，长期看更稳`
  - 没有任何连续 5 个字和原文一样 → 相似度 **0%** → 通过

同时系统会找出改写稿和原文**最长的一段相同文字**，用于在编辑器里提示「这一段照搬了」。

## 5. 原清单里的「校准」是什么意思

「30%」和「每组 5 个字」是**经验默认值**，任务书当时约定：上线前找 **≥10 组真实的「对标原文 + 改写稿」**，由人工判断「算不算抄」，再看系统的判断是否一致，必要时调整这两个数（任务书 AC-R3 / 跟进项 F3）。

这就是原清单 D5 想请业务方提供的东西——**不是必须现在做的**：不校准，系统就按 30% / 5 字运行。

## 6. 建议

**保留查重功能，取消「上线前校准」这一步。**

- 它只影响「素人线 + 对标改写」一个场景，对其他生产线没有拦截作用，也不需要任何日常配置；
- 删除它反而会让素人号可以把竞品原文几乎原样提交，送到校对台才被发现（或发出去才被平台处罚）；
- 默认值先用起来。实际使用中如果出现：
  - **误拦**（明明认真改写了还被拦）→ 调高阈值，如 0.4；
  - **漏拦**（明显照搬却通过了）→ 调低阈值，如 0.2；
  - 调整方式：服务端环境变量 `COPY_SIMILARITY_THRESHOLD`（默认 0.3）、`COPY_SIMILARITY_N`（默认 5），改后重启生效。

## 7. 如果决定删除，需要改什么

| 位置 | 改动 |
|---|---|
| `server/src/modules/copy/service.ts` 预检 | 去掉「查重相似度」检查项（素人线不再因相似度被拦） |
| `server/src/modules/copy/text.ts` | `computeSimilarity` 等查重函数可删 |
| 前端提交前检查弹窗 / 编辑器 | 去掉相似度展示与重合片段提示 |
| 文案工坊任务书 | 删除 FR-R2、AC-R2、AC-R3、跟进项 F3，及 §9.8 全局场景 2（对标改写 + 查重） |
| 回归脚本 | `smoke:copy` 中 AC-R2 相关断言 |

改动量约半天，主要是文档与回归脚本同步。
