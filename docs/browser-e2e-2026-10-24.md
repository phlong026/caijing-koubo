# 2026-10-24 浏览器端到端联调报告（发现缺陷与修复）

## 方式

Playwright 驱动真实浏览器（前端 5173 + dev 后端 8787，SQLite + 内存队列 + 第三方 mock），
以三角色（ops / reviewer / admin）逐页操作，走完完整业务链路：
爆款选题（资讯→生成→分配→送入）→ 文案工坊（写稿→预检→提交）→ 审核工作台（三关桩+人工通过）→
人物库（上传分身素材→reviewer 审核→分身/声音 mock 克隆→确认→设默认）→ 视频创作（口播 completed）→
视频剪辑（改字幕→渲染 v1→提交复审）→ 成片复审通过 → 发布管理（建号→扫码 mock 登录→建计划→published）→
任务中心（五节点全绿 + 时间线完整）。

- 素材库一期（`2ce3e64`，含 smoke:material）提交在本地分支 **`feat/material-library`** 上，
  当前分支 `feat/people-library-frontend` 与远端均无此提交（并行会话曾短暂带出后 reset 摘除）。
  **素材库尚未合入主线**，合并时需带上缺陷 #1 的修法（或以本提交为准）。
