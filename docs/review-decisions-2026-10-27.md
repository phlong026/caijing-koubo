## D1 文案二创模型

- **结论**：文案生成（整稿 / 变体 / 选题二创）走第三方中转的 Claude（`COPY_LLM_*`）；百炼（`DASHSCOPE_*`）用于对标视频语音转文案（ASR）。替代文案工坊任务书 A6「文案引擎用百炼 LLM」的约定。
- **代码**：
  - `server/src/config.ts`：`copyLlm.complianceApproved` 缺省由「非生产才开启」改为**所有环境开启**；仍可显式设 `COPY_LLM_COMPLIANCE_APPROVED=false` 临时停用中转（回退百炼）。
  - 启动告警、系统设置说明、`.env.example`、`docs/real-integration-params-2026-10-24.md` 同步改写。
- **注意**：`COPY_LLM_BASE_URL / API_KEY / MODEL` 三项未配齐时仍自动回退百炼，这是兜底行为，不是开关关闭。

## D2 关卡直接退回

- **结论**：自动审核关卡（第 1~3 关）不通过即可直接退回；「通过」只能在待人工复核时给出，不允许跳过关卡。
- **代码**（`server/src/modules/copy/review.ts`）：
  - `onReviewResult`：退回可在 `submitted / gate1~3 / pending_manual` 任一阶段给出，按读到的状态做条件更新；未指明关卡时取当前所处关卡；`rejectedGate` 只接受 `gate1~3 / manual / external`（`external` = 校对台驳回 / 拒收，与 master 的校对台同步一致）；回写带 `copyVersionId` 时须与审核单锁定版本一致。
  - 审核桩联调参数：`POST /copy/:id/submit` 可带 `stubRejectAt: gate1|gate2|gate3` 与 `stubRejectReason`，在指定关卡模拟退回（任务书 §9.8 场景 4）。仅审核桩实际生效时可用（已关闭或已接入校对台时返回 403 `REVIEW_STUB_DISABLED`）。
- **验证**：`smoke:copy` 新增 2 项——第 2 关直接退回后文案为 rejected、关卡与原因可见、关卡记录为 `gate1:pass, gate2:fail`；修改后重提产生新审核单并从第 1 关重新走到待人工复核。

## D3 审核桩默认关闭

- **结论**：测试期间不开审核桩。
- **代码**：
  - `REVIEW_STUB_ENABLED` 缺省改为 `false`（原为「非生产开启」），开启时启动打告警；`npm run smoke:all` 已显式开启，CI 不受影响。
  - 新增 `reviewMode()`：当前文案审核由谁处理——`jiaoduitai`（校对台已接入）> `stub`（审核桩）> `manual`（审核员在审核工作台人工裁决，master P1-7）。`/review/queue`、`/copy/options`（`review.mode`）返回；文案详情的审核单返回 `channel` 与校对台单号。
  - 审核工作台页头按审核方式提示（人工裁决 / 校对台审核）；文案工坊审核面板提示提交去向；**已送校对台的单不再显示「撤回审核」**（校对台无撤回接口，后端原本就会拒绝）。
- **待办（后续补充）**：
  1. 测试环境按人工复核流程跑：文案提交后由审核员在「审核工作台」裁决（四眼原则：不能裁决自己的提交）；或配置校对台。
  2. 审核桩仅保留给本地联调与 CI 冒烟，后续视需要补充其能力或下线。

## D4 审核智能体（校对台）与风险话术

- **结论**：审核智能体即校对台（master 提交 67cdb0c 已接入：送审、轮询、通过后以返回文案为审定版本、驳回退回可编辑）。合规词表的本地扫描保留为提交前自检，最终以校对台审核为准；风险提示话术以校对台返回为准。
- **发现的问题**：
  1. 校对台 v1.1 接口只返回审核后正文 `content_text`，没有独立的风险话术字段；
  2. 视频创作取稿的 `riskHint` 一直回退模板话术——校对台审定稿是 `origin=review` 的新版本，按「版本 → 审核单」反查不到，即使有追加话术也读不到。
- **代码**：
  - 预留 `JIAODUITAI_RISK_FIELD`（系统设置「校对台 → 风险话术字段名」）：填写后，从审核结果中取该字段作为追加话术写入审核单；未填写或结果中没有时，取稿仍用模板话术兜底，保证成片带风险提示。
  - `getApprovedCopy`：按版本反查不到审核单时，取该文案最近一张通过的审核单。
  - 文案工坊编辑器的风险提示预览块：审核单有返回话术时优先显示。
- **验证**：`test:jiaoduitai` 新增 1 组——配置字段名后取稿 `riskHint` 等于校对台话术；未配置时不采用该字段、回退模板话术。单测 `extractRiskText` 5 个断言。
- **待联调确认**：校对台实际返回的话术字段名（文档第 4 节未给出），确认后在系统设置中填写即可，无需改代码。
